1. 快速开始

上传设计图

点击“上传图片”或把平涂拆件图拖入工作台。背景尽量统一、色块边界清晰时识别效果最好。

检查自动识别

系统会把较大的部分识别为“主区域”，把嘴巴、眼睛、小装饰等识别为“细节区域”。右侧列表显示每个区域的推荐色号。

修正漏检或误分

使用“补区域 / 画笔＋ / 橡皮 / 画线拆分 / 合并所选”修正。无需为了一个漏掉的嘴巴反复调全局参数。

确认配色

查看候选色、可信度、跨色卡比较和配色预览，需要时保存 A/B 两套方案。

导出制作信息

最终可导出色号 CSV、BOM 采购表、配色预览、标注图和色卡连线图。

2. 内置色卡：樱花、涵特 与 亚丽丝

樱花

樱花现已扩展为 600 色。原有 QQ001–QQ360 / TQ361–TQ480 保持不变，本次按方案 A 只补充 TQ481–TQ600。

涵特

涵特色卡现已补齐为完整 720 色，覆盖 001–720。此前缺失的 301–400 已由补充的 10×10 色卡页录入。

亚丽丝

第三套色卡，共 1680 色，来自 12 张 75D 涤纶绣花线色卡照片。高置信厂家印刷色号直接显示；少量低置信位置使用 AL 内部编号。

怎么切换

页面右上角色卡下拉框选择“樱花”“涵特”或“亚丽丝”。切换后，系统会针对同一批区域重新计算最佳色号、候选色和 ΔE00；各色卡的人工选择会分别记忆。

色卡来自图片采样，受到拍摄光线、白平衡、屏幕和毛线材质影响。网站给出的是“视觉最近匹配”，不是实验室测色结果。
亚丽丝色号读取说明：亚丽丝的印刷色号不是连续编号。网站会优先显示高置信识别到的厂家色号；对低置信或重复冲突位置使用唯一 AL 编号，并保留页 / 行 / 列定位，避免错误标注。

3. 项目保存 / 恢复与多张拆件图

项目名称

顶部 PROJECT 输入框用于给当前娃娃命名，名称会进入保存文件。

保存项目

点击“保存项目”下载 .plushcolor.json，包含多图、区域编辑、联动、色卡选择、A/B 方案及自定义色卡。

打开项目

选择之前保存的项目文件即可继续工作，而不是重新识别。

恢复最近项目

浏览器会在本地 IndexedDB 自动保存最近状态；出现“恢复最近项目”时可继续上一次工作。

添加设计图

“＋ 添加设计图”可把头部、身体、服装、配件等多张拆件图放进同一个项目。顶部页签用于切换。

打印制作单

把当前项目关键配色和 BOM 转成适合打印的页面，方便制作时放在手边。

4. 自动识别与四个参数

参数作用什么时候调整
主区域最小面积决定多大的块才作为主要部件保留。区域太多时略调高；重要大部件被过滤时调低。
背景容差决定与背景有多接近的颜色会被当作背景。背景边缘杂色多时调高；主体浅色边缘被吃掉时调低。
相邻区域合并强度控制相邻、颜色接近的碎块是否合并。一个部件被分太细时优先调高；不同色块误合并时调低。
细节识别灵敏度控制嘴巴、眼睛、小装饰等小区域的保留力度。小细节漏检时调高；小噪点太多时调低。

修改参数后点击“按当前设置重新识别”。重新识别会重新生成自动区域，因此正式精修前建议先确定大致参数。

5. 区域编辑工具

选择

默认模式。点击画面编号或右侧区域卡片，选择要编辑的区域。

＋ 补区域

适合“整个嘴巴/小装饰完全没识别出来”。开启后点击目标色块，系统从点击点进行局部区域生长并加入新区域。

画笔＋

适合“区域有了，但边缘少了一块”。先选中区域，再在画面上涂抹，把像素加回当前区域。笔刷滑块控制大小。

橡皮

适合“区域长多了或包含错误部分”。选中区域后涂抹，删除多余像素。

画线拆分

适合两个本应分开的部件被连成一个区域。选中区域后，在需要切断的位置拖/画一条分割线。

合并所选

勾选多个实际上属于同一个部件的区域，再点击合并。适合自动识别过碎的情况。

联动所选

把左/右耳、左右眼、重复衣片等设成同一联动组。之后改一个区域的色号，同组会同步。

解除联动

取消所选区域的联动关系，之后可以独立选色。

重复部件建议

根据面积、比例、颜色等提示可能成对或重复的部件，确认后再联动。

撤销编辑 / 撤销补充 / 清空补充

用于快速回退最近的区域编辑或手动补区域；“清空补充”只清除手工补回的区域。

6. 区域与色号面板

每张区域卡片显示原图颜色、推荐色号、ΔE00 和候选色。可以直接修改区域名称，例如“前发”“左眼”“领带”。

主区域 / 细节

主区域表示较大的物理部分；细节通常挂在某个主区域下，如脸部中的嘴巴、眼睛。

忽略 / 加入匹配

黑、白、肤色默认可忽略；如果某个被自动忽略的颜色实际需要买线，点击“加入匹配”。

候选色

系统默认展示前几名近似色。视觉上更喜欢第二名时可以直接点击替换。

全部色号

打开完整色卡选择器，可通过色号或名称搜索并人工指定。

7. 匹配可信度 / 风险提示

可信度不只看第一名 ΔE00，还参考第一名与第二名的距离差。如果两个候选几乎一样接近，系统会提示“候选接近”。

提示怎么理解建议
很高 / 较高最佳匹配色差较小，并且明显优于第二名。通常可以直接采用。
一般存在肉眼可见差异，或者候选之间差距不大。打开配色预览，并比较前 2–3 个候选。
低 / 候选接近色卡中没有特别接近的颜色，或多个候选难分高下。人工选择，并优先结合实物线卡判断。

8. 色卡管理器

点击页面右上的“色卡管理”。这里管理内置色卡和以后自己增加的品牌/批次色卡。

从规则网格图片建立色卡

  1. 填写色卡名称、编号前缀、起始编号和编号位数。
  2. 填写每页固定的行数和列数。
  3. 一次选择多张色卡图片；文件名会用于排序。
  4. 点击“生成并保存色卡”，系统采样每格中央区域建立颜色库。

也可以导入/导出色卡 JSON，方便备份和迁移。对实拍色卡，建议所有页面尽量在一致光线、白平衡和曝光条件下拍摄。

8.5 色卡浏览页

用途：直接查看网站从原始色卡中提取出的每一个颜色，既方便挑色，也方便人工核对采样结果。

切换色卡

可浏览樱花、涵特、亚丽丝三套内置色卡。

搜索

支持输入完整 / 部分色号，也支持类似 481-520 的编号区间。

排序

可以按原始顺序、色相、明度、饱和度重新排列，更容易找到想要的颜色。

色块详情

点击色块可以查看 HEX、RGB、Lab、来源位置，以及同一色卡中最接近的颜色。

9. 配色预览

用途：在买线之前查看“设计图换成实际色卡颜色”后的整体感觉。

使用：完成区域和色号选择后，进入“配色预览”标签。系统会把参与匹配的区域替换成当前色卡颜色；满意后可导出 PNG。

10. BOM / 用色与采购

BOM 按整个项目聚合同一色号，告诉你这个颜色用了哪些部件、二维面积占比，并根据经验参数估算克重与团数。

项目总用量估算

输入整个娃娃大致会使用多少克线，用于把二维面积占比换成粗略克重。

每团重量

例如一团 50g，用于估算需要买几团。

库存 / 需购 / 单价 / 已购 / 备注

把 BOM 当作真实采购清单维护。库存会影响需要购买的数量。

成本替代容差

允许在指定 ΔE 范围内寻找库存更多或更便宜的近似色，并生成成本优化方案。

二维面积只能用于相对用色参考，不等于真实毛线消耗。实际用量会受绣线密度、针法、部件厚度和返工余量影响。

11. 限色优化

用途：当设计用了很多接近色，但你希望少买几种线时使用。

使用：输入“最多颜色”，点击“生成方案”。系统基于区域面积与感知色差寻找合并方案，并列出“原色号 → 目标色号”。满意后“应用方案”，也可以“恢复优化前”。

12. 跨色卡比较

同一个设计颜色会同时在所有已安装色卡中查找最佳色。比如一个蓝色可能在“樱花”中 ΔE 3.1，在“涵特”中 ΔE 1.8。这个页面用于判断哪套线卡更接近原设计。

13. 配色方案 A / B

用途：比较两套你都犹豫的配色，例如“更浅的头发方案”和“更还原原图的方案”。

  1. 先选好一套颜色，点击“保存当前为 A”。
  2. 修改部分区域色号，再“保存当前为 B”。
  3. 页面会并排预览 A/B。
  4. 点击“应用 A”或“应用 B”可把对应方案恢复到当前编辑状态。

14. 结果、标注与导出

色号列表 / CSV

逐区域导出原色、最终色号、色卡色和 ΔE00，适合存档或进一步整理。

标注图

在原设计图上显示区域编号，编号与列表对应，适合给制作者查看。

色卡连线图

把设计区域与完整色卡中的目标色号连接起来，类似传统手工“圈色号 + 连线”的参考图。

打印制作单

把项目关键信息整理成打印友好的格式。

15. 安装应用 / 离线使用

支持的浏览器会出现“安装应用”按钮。安装后可像桌面小工具一样打开。Service Worker 会缓存页面、脚本和内置色卡；首次加载完成后，很多操作可以离线进行。

设计图、项目编辑和自定义色卡默认在浏览器本地处理，不需要上传到服务器。

16. 推荐工作流

  1. 新建项目并一次加入所有拆件图。
  2. 用默认识别参数跑一遍，不要一开始就追求参数完美。
  3. 先用“合并所选”解决大部件碎裂，再用“补区域 / 画笔 / 橡皮 / 拆分”处理少数异常。
  4. 给关键部件改名，并给左右/重复部件建立联动。
  5. 在樱花 / 涵特 / 亚丽丝之间做跨色卡比较，重点人工检查低可信度颜色。
  6. 保存 A/B 方案，再通过配色预览做最终选择。
  7. 最后生成 BOM / 限色方案 / 标注图，并保存项目文件。

17. 常见问题

区域还是分得太细

优先提高“相邻区域合并强度”；其次略提高“主区域最小面积”。如果只是少数碎块，直接多选后“合并所选”更快。

嘴巴或很小的细节识别不到

先提高“细节识别灵敏度”。如果只是个别漏检，推荐直接使用“＋ 补区域”，再用画笔/橡皮修边。

点“补区域”后长得太大

使用橡皮擦除多余部分；如果颜色与周围太相近，可以先使用较保守的细节灵敏度再补。

不同色卡推荐差别很大

这是正常现象，不同色卡的可用颜色集合不同。看“跨色卡比较”的 ΔE 与可信度，再结合实物线卡确认。

为什么黑、白、肤色没出现在最终色号列表

默认开启“忽略黑 / 白 / 肤色”。如果这些颜色也需要采购，在对应区域点击“加入匹配”。

刷新页面后项目会不会丢

网站有本地自动保存，但浏览器清理站点数据后可能丢失。重要项目仍建议下载 .plushcolor.json 备份。
