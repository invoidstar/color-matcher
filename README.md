# Plush Color Matcher

面向毛绒娃娃配色与制作规划的纯前端工具。上传平涂拆件图后，按主区域 / 细节区域识别颜色，并使用 CIELAB + CIEDE2000 (ΔE00) 匹配最接近的色卡色号。全部图像处理都在浏览器本地完成。

## v2.1

- **双套色卡**
  - QQ/TQ 480 色
  - 新 720 色自然光参考色卡
- **区域识别与补全**
  - Main + Detail 层级区域
  - 同色但分离的部件分别显示
  - 手动点击补充漏检区域
- **配色预览**
  - 将选定色号直接预览回设计图
  - 支持 PNG 导出
- **BOM / 用色清单**
  - 按色号聚合区域、数量与二维面积占比
  - 支持 CSV 导出
  - 面积占比仅用于相对规划，不等同于实际毛线克重
- **限色优化**
  - 指定最多使用的颜色数量
  - 按区域面积加权的 ΔE00 代价逐步合并近似色
  - 支持应用方案与恢复优化前方案
- 色号列表 / 原图标注 / 色卡连线图 / CSV / PNG 导出

## 新 720 色色卡说明

用户提供的压缩包中包含 21 张图片，其中有 1 张重复的 001–036 页；去重后为 **20 个有效页面 × 36 色 = 720 色**。网站使用各页下半部分“自然光下拍摄的图片”建立数字参考色值。

前四色可识别标签：
- 001 黑色
- 002 大红
- 003 雪白
- 004 本白

由于第二套色卡来自实拍照片，RGB / Lab 数值属于视觉参考值，会受到拍摄光照、相机白平衡、材质反光和显示器等因素影响，不应视为厂商提供的绝对物理色值。
