## 页面展示（开发分支已同步）

- **标题**：留言与反馈
- **页面引导**：使用 Color Matcher 时遇到了问题，或者希望增加什么功能？欢迎分享使用体验、问题反馈与功能建议。无需登录，验证通过后留言会公开展示。
- **发表说明**：留言通过人机验证后公开显示，站长可以回复，也可能隐藏或删除不合适的内容。
- **隐私提示**：昵称和留言正文会公开展示。请不要填写手机号、住址、邮箱、账号凭据等个人敏感信息。
- **附件说明**：仅支持纯文本，暂不支持图片或附件上传。
- **关闭提示**：留言板仍在准备中，暂未开放。配色工作台可以正常使用。
- **成功提示**：留言发布成功，谢谢你的反馈！
- **页脚**：Color Matcher · 留言与反馈 · 让每一条建议都被认真看见。

“未开放”应由 `/api/config` 在运行时显示，不能写死在最终页脚。游客无需 GitHub 账号，只有管理后台使用 GitHub OAuth。
