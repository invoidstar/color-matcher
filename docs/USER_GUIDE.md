# Color Matcher 使用说明 · v4.0

## 基本流程
1. 上传设计图或加载示例，支持多张图纸。
2. 选择樱花 / 涵特 / 亚丽丝色卡并识别。
3. 选中区域，查看色号、候选颜色与匹配可信度。
4. 按需补区域、画笔、橡皮、合并、拆分或设置联动。
5. 在结果区查看色号列表、预览、色卡比较、标注图或限色优化。
6. 导出结果，保存 `.plushcolor.json` 项目。

## 工作台布局
桌面：画布在左、区域列表在右、结果在下方。高级识别参数默认收起。

手机：底部导航在「画布 / 区域 / 结果」之间切换。画布上选区或进入「移动画布」模式；移动模式下可拖动和双指缩放。缩放视图只影响显示，不会修改源图像。移动模式和手工画笔互斥。

更多区域操作中包含合并、联动、解除联动、重复部件建议、撤销补充等。

## 色卡与配色
樱花 600 色；涵特 720 色；亚丽丝 1680 色。也支持自定义色卡导入、导出、校准。
色差基于 RGB → Lab 与 CIEDE2000，实际线材颜色应以实物色卡为准。

## 结果与导出
保留色号列表、配色预览、区域标注、色卡连线图、跨色卡比较、方案 A/B、限色优化。
可下载 CSV 和 PNG，也可打印只含区域配色的参考单。

## 项目管理
图片与项目由浏览器本地处理，支持 IndexedDB 最近项目自动保存及 `.plushcolor.json` 导入导出。
旧版项目的采购、库存、克重及成本字段不再使用，其余图纸、颜色、区域和方案继续兼容。
