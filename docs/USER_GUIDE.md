# Plush Color Matcher 使用说明

> 在线说明书：`guide.html`。本文档是仓库内的 Markdown 版本，便于维护和检索。

## 快速开始
1. 上传平涂拆件图。
2. 检查 Main Region / Detail Region 自动识别。
3. 用补区域、画笔、橡皮、合并、拆分修正少量错误。
4. 在樱花 / 涵特 / 亚丽丝色卡中确认颜色，重点查看低可信度区域。
5. 使用配色预览、A/B 方案、BOM、限色优化。
6. 导出标注图 / 色卡连线图，并保存 `.plushcolor.json` 项目。

## 色卡
- **樱花**：600 色。2026-09-26 使用最新 5 张实拍色卡重新采样全部 QQ001–QQ360 / TQ361–TQ600，旧版提取色值已删除并替换。
- **涵特**：完整 720 色，覆盖 001–720。此前缺失的 301–400 已通过后续补充的 10×10 色卡页录入。
- **亚丽丝**：1680 色 75D 涤纶绣花线色卡。2026-09-26 根据新增近照校准厂家色号 101、102、1786 的对应 RGB；AL0001–AL1680 内部编号保持不变。
- 色卡照片是视觉参考，不等同于实验室测色。

## 项目管理
- **保存项目**：下载完整 `.plushcolor.json`。
- **打开项目**：恢复多图、区域、配色、联动、自定义色卡和 A/B 方案。
- **恢复最近项目**：读取浏览器 IndexedDB 的自动保存。
- **添加设计图**：一个娃娃项目可包含头部、身体、服装、配件等多张图。
- **打印制作单**：生成打印友好的制作参考。

## 自动识别设置
- **主区域最小面积**：大部件保留门槛。
- **背景容差**：背景清理力度。
- **相邻区域合并强度**：相邻近似色碎块的合并力度。
- **细节识别灵敏度**：嘴巴、眼睛、小装饰等小区域的保留力度。

## 区域编辑
- **选择**：选择区域。
- **＋ 补区域**：点击漏检色块，用局部区域生长补回。
- **画笔＋**：给当前区域补像素。
- **橡皮**：删掉当前区域多余部分。
- **画线拆分**：把误连在一起的区域切开。
- **合并所选**：把多个碎块合成一个部件。
- **联动所选**：左右/重复部件共享色号。
- **解除联动**：取消联动。
- **重复部件建议**：自动提示疑似成对/重复部件。
- **撤销编辑 / 撤销补充 / 清空补充**：回退手工操作。

## 区域与色号
- 可以重命名区域。
- 可以忽略或重新加入匹配。
- 可以选择 Top 候选或打开完整色卡手动指定。
- 可信度同时考虑最佳 ΔE00 和第一/第二候选间距。

## 色卡管理器
- 规则网格图片可批量建立自定义色卡。
- 可设置名称、前缀、起始编号、编号位数、行列数。
- 支持色卡 JSON 导入 / 导出 / 校准 / 删除。

## 色卡浏览
- 独立页面：`palette.html`。
- 可以切换樱花、涵特、亚丽丝，并查看每一个提取色块。
- 支持色号与编号区间搜索，例如 `TQ481`、`301`、`481-520`。
- 支持原始顺序、色相、明度、饱和度排序。
- 点击色块可查看 HEX / RGB / Lab、来源位置和同色卡相近颜色。

## 配色与制作工具
- **配色预览**：把设计图区域替换成最终色卡颜色。
- **BOM**：汇总整个项目各色号使用位置、面积占比、估算克重、团数、库存、需购、单价和备注。
- **成本优化**：在允许 ΔE 范围内寻找更省的替代色。
- **限色优化**：把相近颜色合并到指定最大颜色数量。
- **跨色卡比较**：同一区域比较全部已安装色卡的最佳匹配。
- **方案 A/B**：保存两套完整配色并排比较，一键切换。

## 导出
- 色号 CSV
- BOM / 采购 CSV
- 配色预览 PNG
- 标注图 PNG
- 色卡连线图 PNG
- 打印制作单

## 注意
二维区域面积只能作为相对用量参考，不能直接代表真实毛线克重。实际颜色也会受到线材、屏幕、拍摄光线和批次影响。


## 亚丽丝色号说明
亚丽丝色卡来自 12 张实拍图，共 1680 个线穗。网站对线穗颜色做中央区域稳健采样。厂家印刷色号通过图像自动读取；对低置信或重复冲突的识别结果，网站不会强行显示可能错误的厂家色号，而使用对应的 AL 内部编号。色卡选择器会显示页码和位置，方便回到原色卡核对。
